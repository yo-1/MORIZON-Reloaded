about=MORIZON Reloaded — Forest Zoning.
    林野庁の委託事業を通じて開発された森林ゾーニング支援ツール「もりぞん（MORIZON）」を、現在のQGIS環境で利用できるよう再実装した非公式プラグインです。

    オリジナル版が採用する「林業の収益性」と「山地災害リスク」の両面から森林管理の方向性を検討する考え方と、基本的な処理体系を継承しています。そのうえで、QGIS 3.44への対応、利用できなくなった旧処理の再構築、処理の安定化および操作性の改善を行っています。

    謝辞：オリジナル版は、林野庁の委託事業において、日本森林技術協会がゾーニングの考え方と作業フローを取りまとめ、MIERUNEがQGISプラグインとして実装したものです。オリジナル版の開発に携わった皆様に感謝いたします。

    MORIZON Reloaded is an unofficial compatibility port of the original MORIZON forest zoning plugin for QGIS 3.44, developed by Yoichi Wada as a personal technical initiative. It is not an official modification by the Japan Forest Technology Association or the Forestry Agency of Japan.

    Acknowledgements: The original MORIZON was developed through a project commissioned by the Forestry Agency of Japan, with the zoning workflow organized by the Japan Forest Technology Association and the QGIS plugin implemented by MIERUNE.

    External dependencies: this plugin relies on QGIS's bundled GDAL and NumPy, and on matplotlib (bundled with QGIS 3.44's Python environment on Windows). Two processing steps (集材作業効率/cost's ruggedness terrain analysis and 保全対象を含む流域/savearea's watershed delineation) additionally require the GRASS Processing Provider to be enabled in QGIS; the plugin does not install or bundle GRASS itself. No binaries are bundled with this plugin.

changelog=Version 2.3.0 (official release)
    First official release of this compatibility port. Preserves the
    original MORIZON analysis logic, thresholds, scoring structure, and
    four-quadrant zoning classification unchanged; re-implements and
    stabilizes the plugin for QGIS 3.44.x. Full details, including every
    individual fix's verification evidence, are in CHANGELOG.md and
    docs/OPEN_ISSUES.md in the source repository (not bundled in this
    ZIP); summary below.

    Fixed (affect output values):
    - 地利 (road-distance): no longer fills the entire output with a
      sentinel value when the road network doesn't fully cover the DEM
      extent. Verified against real GRASS r.grow.distance.
    - 地形の複雑さ (SHC / terrain complexity): plan curvature was
      systematically overestimated (~1.7x) due to an incorrect
      coefficient-doubling step; removed, now matches real SAGA output
      to floating-point precision.
    - Windows file-lock handling unified across all element writers
      (fixed a Permission-denied failure specific to 集材作業効率/cost).
    - Fixed the scoring tab losing track of a combobox's bound layer
      after a partial element recalculation.
    - Fixed the scoring tab's statistics-display dialog crashing with a
      matplotlib API error.
    - Fixed redundant repeated threshold recomputation after element
      calculation finishes.

    Fixed (UI/stability, no effect on analysis output):
    - Fixed a ~20s apparent UI freeze when opening the scoring/zoning
      tabs (QgsProject() singleton misuse).
    - Long UI stalls unrelated to MORIZON no longer appear as misleading
      Warning-level log entries.
    - Fixed the in-dialog version label drifting from the installed
      version; fixed duplicate/leftover toolbar icons.
    - Fixed a cosmetic false-positive diagnostic warning in aggregation
      (Shapefile DBF field-name truncation).

    Known issues (monitoring continues, see docs/OPEN_ISSUES.md):
    - Scoring tab QML generation fails intermittently for one element;
      root cause and trigger condition not identified. Workaround:
      recalculate the affected element.
    - A full confusion-matrix comparison against an actual run of the
      original (pre-port) MORIZON has not been performed (no access to
      its required legacy SAGA/GRASS stack or original input data in
      this project's development environment); individual formula fixes
      above were each verified directly against real SAGA/GRASS output.
    - The GRASS-Processing-Provider-missing preflight check has not been
      exercised on-device (code-reviewed only).

    See CHANGELOG.md's "Development history" section for the full
    rc1-through-rc3-dev18 diagnostic build log that led to this release.
