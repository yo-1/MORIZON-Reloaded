# Claude / Claude Code 開始プロンプト

MORIZON Reloadedの開発を引き継いでください。作業ルートの`CLAUDE.md`を最優先で読み、次に`docs/HANDOFF.md`、`docs/ARCHITECTURE.md`、`docs/VALIDATION.md`、`docs/OPEN_ISSUES.md`、`README.md`、`NOTICE`、`CHANGELOG.md`(いずれもリポジトリルート直下)を読んでください。

現時点の正本候補はv2.3.0-rc2です。最初のターンではコードを変更せず、次を日本語で提示してください。

1. 理解した目的、現状、非変更条件
2. rc2の構造と主要な依存関係
3. 確定事項・推定事項・未確認事項・要判断事項の区分
4. 正式v2.3.0までの検証計画
5. 最初に実施すべき3件の作業と、それぞれの対象ファイル・完了条件

重要条件:

- 原版の計算体系、しきい値、点数方向、NoData、グリッド、出力名、4象限分類を勝手に変更しないでください。
- 互換修正と方法論変更を明確に分離してください。
- QGISで未実行の項目を「動作確認済み」としないでください。
- 変更前に影響範囲と回帰試験を示してください。
- Windows、QGIS 3.44.x、Python 3.12、日本語パス、ファイルロック、GRASS providerを重視してください。
- 不足資料があれば、必要性と用途を限定して質問してください。
